Older versions buried overlays in a table of preferences. Aerial 4 replaces that with a visual editor: pick a zone (top left, top center, top right, center, bottom left, bottom center, bottom right), drag in a clock, date, location, weather, music, battery, timer, countdown or a message of your own, and watch it appear on a live preview. Fonts, colors, shadows, margins and timing are all right there, per zone.

Each display can have its own layout, and the wallpaper keeps a separate set from the screensaver, so you can run a busy layout on the screensaver and a quiet one behind your windows. The music overlay shows what's playing in any audio app, the same way the Now Playing widget does, and an option keeps overlays visible on the lock screen.
