Aerial has shipped as a `.saver` plug-in, as an app-extension screensaver, and now as a wallpaper extension. This section collects what that work taught, as sample code and notes for developers building their own macOS screensavers.

## Screensaver extensions

Since macOS 10.15 (2019), the screensavers that ship with the system started moving from being `.saver` plug-ins to app extensions. To date, Apple has not published that extension point for third-party developers. This series documents the [AppexSaverMinimal](https://github.com/AerialScreensaver/AppexSaverMinimal) sample project through observations made from the system's own bundles. It has only been tested on macOS 14 up to macOS 27.
