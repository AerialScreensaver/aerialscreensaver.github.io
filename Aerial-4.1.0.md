This version does **NOT** work on Sequoia. If you still use macOS Sequoia, use 4.0 until you upgrade your mac. You should not be prompted to upgrade on older systems. If you are, please deny the update! 

What's new (compared to the betas) :
- Proper support for macOS Golden Gate (and Tahoe).
- Add migration for external drive to the new sparsebundle system (many thanks to Brian (@brian163) for his help testing the original system)
- macOS 27 feed. On top of the new videos, you'll also find a new Wallpaper section with some system videos that can be added (or not) to your rotations. Add support for the new localization format used by Apple.
- Add trim cache button to manually trim  your cache if you feel so inclined.
- Increase visibility of Aerial version in the popover menu
- Extra fixes

Important : 
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings. 
- If you have an issue, please use Settings > Advanced > Export Diagnostics to generate the logs before posting about your issue in Discord or Github, it will help immensely !
