What's new :
- Bring back support for the Music overlay to support all audio apps, just like the Now playing widget. Many thanks to Jonas van den Berg (@ungive) for their workaround to support the `mediaremote` framework again. 
- Add override options for users who want different screensaver configurations whether plugged into external monitors or not. See the Settings > Displays options and change from "All screens" to selected screens to see your options. 
- Code review/better threading model. With big thanks to Josh Michaels (@zeromhz) for the help ! 

Important : 
- Requires macOS 26/27. See Aerial's website for older systems. 
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings. 
- If you have an issue, please use Settings > Advanced > Export Diagnostics to generate the logs before posting about your issue in Discord or Github, it will help immensely !
