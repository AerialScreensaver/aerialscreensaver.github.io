This version does **NOT** work on Sequoia. If you still use macOS Sequoia, use 4.0 until you upgrade your mac. You should not be prompted to upgrade on older systems. If you are, please deny the update! 

What's new :
- Fix two New York videos not showing at the right time. Thanks to @BloobyBabyYoshi on Discord for reporting this !
- Fix screensaver sometimes not starting, in some scenarios that were mishandled with the wallpaper off. Thanks to @deki-haibane for reporting the issue ! 

Important : 
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings. 
- If you have an issue, please use Settings > Advanced > Export Diagnostics to generate the logs before posting about your issue in Discord or Github, it will help immensely !
