This version does **NOT** work on Sequoia. If you still use macOS Sequoia, use 4.0 until you upgrade your mac. You should not be prompted to upgrade on older systems. If you are, please deny the update! 

What's new (compared to the betas) :
- Add optional "Don't resume videos" for screensaver mode only, if you want to make sure each screensaver start gives you a new video (as 3.X used to do). This is disabled by default. 
- Add optional restart wallpaperagent button, if you keep experiencing issues with wallpaper/screensaver, you can enable it at the bottom of the Settings > Wallpaper panel
- Fix screensaver sometimes showing accelerated video at startup
- Improvement on migration from 4.0 with a custom cache folder that is on your main drive, thanks to @Starksoft ! 
- Improvement on migration from 3.x with a custom cache folder

Important : 
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings. 
- If you have an issue, please use Settings > Advanced > Export Diagnostics to generate the logs before posting about your issue in Discord or Github, it will help immensely !
