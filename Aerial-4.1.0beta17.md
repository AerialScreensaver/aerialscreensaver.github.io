This version does **NOT** work on Sequoia. If you still use macOS Sequoia, use 4.0 until you upgrade your mac. 

What's new :
- Fix external location for Cache and Expansions. If you want to store your cache on an external drive, Aerial will create a sparsebundle and mount it inside `/Users/Shared/Aerial` where you can directly access it. 
- Probable fix for misdetected orientation for Mavic 4 videos. 

Important : 
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings. 
- Use Settings > Advanced > Export Diagnostics to generate the logs before posting about your issue in Discord or Github, it will help !
