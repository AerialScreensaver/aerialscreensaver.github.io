What's new :
- Add optional menubar background (white, black, or tinted from the current video) if you are bothered with the menubar switching from light/dark too often  
- Fix some system logs issues
- Fix Aerial requesting audio playback permissions when audio playback was disabled  
- Remove wallpaper cache cleanup feature which is no longer used with 4.1 
- Bring back options to set when the screensaver should start in Settings
- Cleanup of Settings (still some work to do)
- Bump dependencies, PaperSaver 0.4.2

Important : 
- Requires macOS 26/27. See Aerial's website for older systems. 
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings. 
- If you have an issue, please use Settings > Advanced > Export Diagnostics to generate the logs before posting about your issue in Discord or Github, it will help immensely !
