If you are using macOS Tahoe or Golden Gate beta, you probably want to try the 4.1 beta instead of this, you can switch to beta directly in the app in Settings > Auto update.

Version 4.0.X is recommended only if you use macOS Sequoia. 

What's new :
- Bring modern pause architecture from 4.1 to fix a bunch of bugs
- Fix crashes related to screen connect/disconnect
- Fix a bunch of bugs related to Time management

Important : 
- Check the FAQ if you have issues here : https://aerialscreensaver.github.io/faq/ 
- If things don't work, open the app settings and look at the checklist on top. You should get buttons to resolve issues if any.
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings.
