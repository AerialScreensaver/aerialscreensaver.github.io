What's new :
- Add monospaced digits, enabled by default, for fonts that support them. This improve the visuals of Clocks/Date overlays. 
- Add detection for Intel Macs on macOS Golden Gate. Because Homebrew is no longer supported on these configuration, macports will be suggested as an alternative when third party tools are required. FAQ with more information is available. 
- Live feeds can now have a time slice (day/sunset/night/sunrise). They can also be added to playlists. 
- Allow right click on videos in the menubar menu, Home view and Live feeds.
- Fix issues preloading Live feeds on paused desktop wallpaper.
- Bump dependencies, PaperSaver 0.4.1

Important : 
- Requires macOS 26/27. See Aerial's website for older systems. 
- You can start fresh if you get stuck by deleting `/Users/Shared/Aerial`. It resets *everything*, including settings. 
- If you have an issue, please use Settings > Advanced > Export Diagnostics to generate the logs before posting about your issue in Discord or Github, it will help immensely !
